Private household assistant

Sema

Sema is a private assistant operated by Beltsazar Krisetya for authorised members of the Setyamarta household. Its purpose is to help those household members work with their own Google accounts after they grant permission.

Sema is not a public product, marketplace, or social network. It is not a Google product. Google and Google product names are trademarks of Google LLC. Sema is not affiliated with, sponsored by, or endorsed by Google.

Purpose of the application

The purpose of Sema is to provide a private household assistant that can carry out requested tasks against an authorised Google account. An account owner first grants Sema permission through Google’s OAuth consent screen. After that grant, an authorised household user can ask Sema to find, summarise, organise, create, update, or send information that already belongs to that Google account.

Sema exists so that household members do not have to switch between several Google products for ordinary household work such as finding a message, checking whether a calendar is free, locating a file, updating a contact, or adding a task. Sema uses Google user data only to provide or improve those user-facing assistant features. It does not use Google user data for advertising, sale, credit decisions, or training of non-personalized artificial intelligence models.

Who Sema is for

Sema is for authorised members of the Setyamarta household. The current authorised Google accounts are household accounts owned or administered by those members. A person who does not own or administer a connected account cannot use Sema to reach that account.

This website does not provide a way to create an account, sign in, or connect a Google account. Account connection happens only through Google’s own OAuth consent flow on a private host, not on this public information site.

Functionality and features

After an account owner grants the relevant Google permission, Sema can provide the following user-facing features.

Mail: Sema can search, read, label, organise, draft, and send Gmail messages when asked. It uses Gmail content only to complete the requested mail task, such as finding an email, preparing a reply, or applying a label.

Calendar: Sema can list calendars, read events, check availability, create or update events, and send event changes when asked. It uses Calendar data only to complete the requested scheduling task.

Files and documents: Sema can find Drive files, read metadata and permitted file content, and work with Docs, Sheets, or Slides when asked. It uses Drive and document data only to complete the requested file or document task.

Contacts and people: Sema can look up and update Contacts or People records when asked. It uses contact data only to complete the requested address-book task.

Tasks: Sema can list, create, update, and complete Google Tasks when asked. It uses task data only to complete the requested reminder or to-do task.

Wider household account features: the Sema household account may also use Chat, Classroom, Drive Activity, Drive Labels, Forms, Sites, Meet, Apps Script, Analytics, Search Console, AdSense, Ads, YouTube, Photos, and Photo Picker when those scopes have been granted and a requested feature needs them. Google Maps is not requested.

How Sema uses Google user data

Sema accesses Google user data only after the account owner grants OAuth permission. The data accessed depends on the scopes granted to that account. Sema then uses that data to provide the assistant feature the authorised user requested.

Examples: if a user asks Sema to find last week’s school email, Sema may read Gmail messages and return the relevant result. If a user asks whether Saturday afternoon is free, Sema may read Calendar events and return availability. If a user asks Sema to locate a household spreadsheet, Sema may search Drive and open the matching file. If a user asks Sema to add milk to a shopping task list, Sema may create or update a Google Task.

Sema does not collect Google user data through this website. This homepage, privacy policy, and terms page do not receive Google account content, OAuth tokens, or sign-in credentials. Google user data is processed on a private, access-controlled host after a successful OAuth grant.

A full description of the Google user data Sema accesses, uses, stores, shares, retains, deletes, and protects is in the Sema privacy policy. That privacy policy is the same policy linked from the Google OAuth consent screen.
